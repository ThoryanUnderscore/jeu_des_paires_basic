# jeu_des_paires_basic
Petit jeu des paires simple affichable dans la console avec pdCurses sur Windows.

Déplacement :
Z -> Haut/Up  
S -> Bas/Down
Q -> Gauche/Left
D -> Droite/Right

Retournez les "cartes" avec Espace/Spacebar

Time skip de 1 seconde à chaque retournement

Système de compteur de coups (affichés à la fin du niveau)
